# AIMI

**매일 쌓이는 나의 AI 감각**

이미지를 설명하는 키워드를 찾고, 질문을 다듬고, 내 작업에 맞는 AI 모델을 비교하는 **앱인토스 미니앱**입니다. 짧은 미니게임과 정원 꾸미기를 연결해 AI를 배우는 경험을 일상의 습관으로 만들고자 합니다.

**앱인토스 배포 완료 · 2026-11-13 기준**  
토스 앱에서 AIMI를 이용할 수 있습니다. 이 저장소는 미니앱 프론트엔드, 서버 API, 공유 규칙과 콘텐츠를 관리합니다.

## 주요 기능

| 기능 | 이용 방법 |
| --- | --- |
| 이미지 챌린지 | 목표 이미지를 보고 대상·개수·색상·배경·그림체 등을 설명하는 키워드를 선택합니다. |
| 일별 학습 해설 | 챌린지가 끝나면 정답 프롬프트와 작성 포인트, 실제 생성 모델의 가이드에 연결한 설명을 확인합니다. |
| 프롬프트 개선 | 기존 의도를 다듬은 개선안과 조건을 더한 확장안을 비교하고, 직접 수정하거나 복사합니다. |
| AI 모델 추천 | 텍스트·이미지·영상 중 필요한 출력 형태를 고르고 작업을 입력해 모델을 비교합니다. |
| 미니게임 | 폴짝 길건너기·점프 달리기·숲길 달리기로 챌린지 예산을 모읍니다. |
| 정원·상점 | EP로 아이템과 캐릭터를 구매하고 정원에 드래그해 배치합니다. |
| 소셜 | 친구 코드로 요청을 보내고 수락한 친구의 정원과 챌린지 기록을 확인합니다. |
| 계정 관리 | 닉네임 변경, 개인정보처리방침 확인, 로그아웃·계정 삭제를 제공합니다. |

## 하루의 이용 흐름

1. 출석하고 오늘의 팁을 확인합니다.
2. 요일별 미니게임을 플레이해 이미지 챌린지 예산을 모읍니다.
3. 목표 이미지를 설명하는 단어를 고르고 조합 문장을 확인합니다.
4. 결과를 참고해 다시 시도하거나, 최종 해설에서 정답과 작성 방법을 배웁니다.
5. 획득한 EP로 정원을 꾸미고 친구의 정원을 방문합니다.

프롬프트 개선과 모델 추천은 홈에서 별도로 이용할 수 있습니다.

### 이미지 챌린지

- 목표 이미지는 미리 생성·검수한 콘텐츠입니다. 사용자의 선택마다 새 이미지를 생성하지 않습니다.
- **LLM 채점이 아니라 서버의 키워드 집합 비교로 판정**합니다.
- 제출 비용은 **30예산**으로 고정이며 단어·모델별 추가 비용은 없습니다.
- 정답 개수 힌트는 **15예산**으로 하루의 해당 챌린지에서 한 번 구매합니다. 구매 후에도 제출할 예산이 남아야 합니다.
- 맞은 단어·다시 확인할 단어·일치율과 이전 조합 내역을 확인할 수 있습니다.
- 성공하거나 남은 예산으로 더 시도할 수 없으면 종료됩니다. 첫 제출 이후에는 미니게임으로 예산을 추가하지 않습니다.
- 해설에는 검수한 **정답 프롬프트 하나**, 번호형 작성 포인트, 생성 모델 정보가 표시됩니다.
- 현재 준비된 일별 콘텐츠는 이미지 챌린지 **10개**와 오늘의 팁 **10개**입니다.

### 미니게임

| 게임 | 모바일 조작 | 기본 편성 |
| --- | --- | --- |
| 폴짝 길건너기 | 탭 전진·방향 스와이프·방향 버튼 | 월·목·일 |
| 점프 달리기 | 탭 점프·꾹 누르면 착지 후 연속 점프 | 화·금 |
| 숲길 달리기 | 좌우 스와이프·방향 버튼 | 수·토 |

하루 최대 5회 플레이하며, 각 게임은 100점에 도달하면 완주합니다. 플레이마다 발급한 시드와 게임 규칙 버전으로 장애물·코인을 구성하고, 서버가 입력 기록을 재생해 점수와 보상을 검증합니다.

### 프롬프트 개선·모델 추천

- 프롬프트 개선과 업무 분석은 서버에서 **Google Gemini**를 호출합니다. API 키는 앱에 포함하지 않습니다.
- 기본 일일 한도는 **프롬프트 개선 5회 / 모델 추천 분석 5회**로 각각 관리하며, 화면에 남은 횟수를 표시합니다. 실제 한도는 서버 설정을 따릅니다.
- 개선기에서 추천 화면으로 이동하는 것만으로 차감하지 않습니다. 실제 업무 분석·추천 요청을 보내면 추천 한도를 사용합니다.
- LLM은 작업과 요구 기능, 적절한 모델군을 분석합니다. 세부 모델 선정은 **공개 데이터와 코드 기반 조건·비용 비교**로 처리합니다.
- Small·Medium·High는 AIMI의 **경량·효율형 / 균형형 / 고성능형 모델군**입니다. 같은 모델의 추론 강도나 공개 파라미터 크기 구분을 뜻하지 않습니다.
- 텍스트는 지원 기능·검증된 품질 자료·가격을, 이미지·영상은 제작 지원 조건과 계산 가능한 공개 가격을 비교해 적격 후보를 최대 3개 추천합니다.
- 모델 자료는 OpenRouter·Artificial Analysis의 수집 자료와 검수한 정책을 사용합니다. AA 지표가 없는 모델에 임의 점수를 채우지 않습니다.
- 현재 카탈로그 기준: **텍스트 144개 / 이미지 45개 / 영상 25개**. 수와 제공 상태는 자료 갱신에 따라 달라집니다.
- 추천 비용은 명시된 작업량·설정에 따른 비교치이며, 실제 청구액이나 생성 품질을 보장하지 않습니다.

### 소셜

```text
A가 B의 코드로 요청 → B의 소셜 목록에 요청 표시
→ B가 수락 → 양쪽 친구 등록 → 서로 정원 방문
```

친구에게는 닉네임·선택한 캐릭터·배치된 정원·오늘 챌린지 성공 여부·누적 성공 횟수가 표시됩니다. 친구를 꾹 누르고 삭제를 확인하면 **양쪽 친구 관계가 해제**됩니다. 수락한 친구에게는 정원이 자동 공개됩니다.

푸시 알림이나 실시간 구독 방식은 아니며, 목록을 다시 조회할 때 변경 사항을 반영합니다. 초대 링크는 미니앱으로 연결하고 친구 요청을 자동 수락하지 않습니다.

## EP와 챌린지 예산

**EP는 정원 상점용 재화이고, 챌린지 예산은 제출·힌트에 쓰는 별도 자원입니다.** EP는 현금이나 토스포인트로 환전하지 않습니다.

| EP 획득 경로 | 규칙 | 하루 최대 |
| --- | --- | ---: |
| 출석 | 한국 날짜 기준 1회 | 3 EP |
| 오늘의 팁 | 확인 보상 1회 | 1 EP |
| 미니게임 | 판마다 코인 4~7개 중 실제 획득 수만 지급, 한 판 최대 7 EP | 15 EP |
| 챌린지 | 첫 성공 기본 10 EP + 남은 예산에 따른 보너스 0~5 EP | 15 EP |
| **합계** | 현재 보상 정책 기준 | **34 EP** |

챌린지 보상은 성공 후 안내에서 확인할 때 한 번 지급합니다. 정원 배치·캐릭터 변경은 무료이며, 아이템은 수량 구매와 남은 수량 표시를 지원합니다.

금액·가격의 공통 원본: [`packages/contracts/src/economy.ts`](packages/contracts/src/economy.ts).

사용자 식별에는 `User.createAnonymousKeyAuthCode()`와 서버의 코드 교환을 사용합니다. 같은 식별자로 다시 접속하면 기존 계정과 기록을 불러옵니다. 닉네임이나 친구 코드는 로그인 비밀번호가 아닙니다.

```text

packages/contracts/    공유 타입·Zod 스키마·보상/정원 규칙
packages/game-core/    게임 시뮬레이션·버전별 replay 규칙
packages/recommender/  모델군·지원 조건·비용 비교
content/               챌린지·일별 일정·모델 자료
supabase/migrations/   PostgreSQL migration
assets/licenses/       외부 에셋·폰트 등의 라이선스 기록
```

## 로컬 개발

Node.js **22.12 이상**과 npm을 사용합니다. 저장소 루트에서 실행하세요.

```sh
npm ci
AIMI_AI_MODE=fixture npm run dev
```

- 미니앱: `http://127.0.0.1:5180`
- 개발 API: `http://127.0.0.1:8081` — 프론트의 `/api` 프록시로 연결
- 개발 인증·초기 125 EP·예시 AI 응답은 로컬 확인용입니다. 실제 서비스 계정과 분리됩니다.
- 기본 설정에서는 API 재시작 시 개발 기록이 초기화됩니다. 새로고침만으로는 초기화되지 않습니다.
- `AIMI_DEV_PERSIST_STATE=true`로 설정한 경우에는 로컬 상태를 파일에 보관합니다.
- 종료는 실행 터미널에서 `Ctrl+C`. API 코드 변경 후에는 서버를 재시작합니다.

### 환경변수

실제 값은 `.env.local` 또는 Render의 서버 환경변수·Secret Files에 보관합니다. 예시는 [서버 설정](apps/api/.env.example), [프론트 설정](apps/miniapp/.env.example)을 참고하세요.

| 위치 | 주요 설정 |
| --- | --- |
| `apps/api/.env.local` | `DATABASE_URL`, `SESSION_SIGNING_KEY`, `AIMI_GEMINI_API_KEY` |
| 서버 AI 설정 | `GEMINI_TEXT_MODEL`, `OPTIMIZER_DAILY_LIMIT`, `RECOMMENDATION_DAILY_LIMIT` |
| 운영 인증 | `TOSS_CLIENT_CERT_PATH`, `TOSS_CLIENT_KEY_PATH` |
| 운영 통신 | `CORS_ALLOWED_ORIGINS`, Supabase·콘텐츠 설정 |
| migration 실행 환경 | `MIGRATION_DATABASE_URL` |
| `apps/miniapp/.env.local` | 공개 API 주소인 `VITE_API_BASE_URL` |

`AIMI_GEMINI_API_KEY`, DB 접속 정보, 토스 인증서·개인키 등 서버 비밀값은 `VITE_` 변수나 Git에 넣지 않습니다. 운영에서는 개발 인증·공유 테스트 계정을 활성화하지 않습니다. 기존 토스 OAuth용 연결 해제 설정은 익명 인증 경로와 구분합니다.

### 검사와 번들 생성

```sh
npm run typecheck
npm run build
npm test

VITE_APP_RUNTIME=toss VITE_TEST_DEMO=false \
VITE_API_BASE_URL=https://aimi-online-api.onrender.com \
npm run ait:build
```

생성 파일은 `apps/miniapp/aimi.ait`입니다. 로컬 개발 서버 실행, `.ait` 생성, 콘솔 업로드, 토스 실기기 테스트, 심사·배포는 각각 별도 단계입니다. 저장소의 과거 점검 기록은 당시 시점의 기록이며, 현재 배포 상태와 구분해 읽어주세요.
