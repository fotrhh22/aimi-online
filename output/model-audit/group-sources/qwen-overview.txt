<h1 class="page-title">Alibaba Cloud Model Studio:Text Generation and Visual Understanding</h1>
<div class="doc-status">
Last Updated:Nov 05, 2026

<article class="product-description markdown-body">

<meta property="og:title" content="Text Generation and Visual Understanding"/><div lang="en" class="icms-help-docs-content"><p data-tag="shortdesc" class="shortdesc">Qwen Plus, Max, and Flash accept text, images, and video and respond with text. Use the same model to generate content, understand images, or analyze video. Image or video input alone does not require switching to a VL model.</p>
<h2 id="choose-a-model">Choose a model <span id="oc1a2b3c4d5e02"></span> <span id="oc1a2b3c4d5e01"></span> <span id="mg1a2b3c4d5e02"></span> <span id="mg1a2b3c4d5e01"></span> <span id="t1a2b3c4d5e6f8"></span> <span id="t1a2b3c4d5e6f7"></span> <span id="h3-office-productivity"></span> <span id="v7a002"></span> <span id="v7a01d"></span> <span id="t1a2b3c4d5e701"></span> <span id="t1a2b3c4d5e700"></span> <span id="v7a005"></span> <span id="v7a004"></span> <span id="v7a008"></span> <span id="v7a007"></span> <span id="t1a2b3c4d5e709"></span> <span id="t1a2b3c4d5e708"></span> <span id="t1a2b3c4d5e713"></span> <span id="t1a2b3c4d5e712"></span> <span id="v7a011"></span> <span id="v7a010"></span> <span id="t1a2b3c4d5e721"></span> <span id="t1a2b3c4d5e720"></span> <span id="v7a019"></span> <span id="v7a018"></span> <span id="t1a2b3c4d5e725"></span> <span id="t1a2b3c4d5e724"></span></h2>
<p>Plus, Max, and Flash accept text, images, and video and respond with text. Text generation creates or processes text based on your input. Image and video understanding interprets visual content and answers questions, including tasks that combine visual input with text instructions.</p>
<ul>
<li><strong>Start here</strong>: <code>qwen3.7-plus</code> balances capability and cost.</li>
<li><strong>Prioritize quality</strong>: <code>qwen3.8-max</code> for tasks with higher reasoning and understanding requirements.</li>
<li><strong>Prioritize cost</strong>: <code>qwen3.8-flash</code>; verify that results meet your requirements.</li>
</ul>
<p>Get started with <a href="/help/en/model-studio/text-generation">Text generation</a> and <a href="/help/en/model-studio/vision">Image and video understanding</a>.</p>
<p><strong>Deep thinking</strong>: Use step-by-step reasoning for problems that require multiple stages of analysis, allowing the model to reason more thoroughly before answering. Adjust the thinking mode to suit your task. See <a href="/help/en/model-studio/deep-thinking">Deep thinking</a>.</p>
<p><strong>Tool calling</strong>: Models can call tools based on your input. Function Calling connects functions or business APIs that you define. Built-in tools provide web search, a code interpreter, and web scraping to retrieve external information or process data. See <a href="/help/en/model-studio/tool-calls">Tool calling</a>.</p>
<p><strong>Structured output</strong>: Organize information from text, images, or video into valid JSON for programs to read, validate, and process. See <a href="/help/en/model-studio/qwen-structured-output">Structured output</a>.</p>
<p><strong>Batch inference</strong>: For large numbers of requests that do not require immediate results, batch inference can reduce request costs. See <a href="/help/en/model-studio/batch-inference">Batch inference</a>.</p>
<h2 id="domain-specific-models">Domain-specific models</h2>
<p>For specific tasks, you can also choose a model optimized for that task.</p>
<ul>
<li><a href="/help/en/model-studio/machine-translation">Translation</a>: Qwen-MT translates text across languages.</li>
<li><a href="/help/en/model-studio/long-context-qwen-long">Long documents</a>: Qwen-Long processes very long documents through file uploads and references.</li>
<li><a href="/help/en/model-studio/role-play">Role-playing</a>: Qwen-Character supports human-like conversations that maintain a defined persona.</li>
<li><a href="/help/en/model-studio/data-mining-qwen-doc">Data mining</a>: Qwen-Doc extracts information, classifies content, and generates summaries from documents.</li>
<li><a href="/help/en/model-studio/qwen-deep-research">Deep research</a>: Qwen-Deep-Research plans research steps and uses multiple rounds of web search to produce research reports.</li>
<li><a href="/help/en/model-studio/qwen-vl-ocr">Text extraction</a>: Qwen-OCR extracts text from images of documents, tables, or handwriting.</li>
</ul>
<p>Regions and invocation methods vary by model. See the linked guides for details.</p>
