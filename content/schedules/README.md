# 일일 편성

`daily-program-v1.json`: 요일별 게임과 오늘의 팁10개. 날짜는 서버 Asia/Seoul을 기준으로 정하고 팁은 tipStartDate부터10일 순환한다. 기존 일일 기록과 진행 중인 게임 종류는 바꾸지 않는다. 수정 시 version을 올린다.

게임: 월·목·일 길 건너기 / 화·금 Dino / 수·토 Temple Run.

챌린지는 아직 fixture.ts 예시다. 생성기에서 준비한10개는 미생성·미승인이므로 발행 목록에 넣지 않는다. 생성·시각 검수 후 승인된 버전과 날짜 일정을 등록하고 v2 서버 평가기에 연결해야 한다. 일일 팁은 챌린지 정답과 무관한 일반 작성 팁이며, 문제별 종료 후 팁과 구분한다.
