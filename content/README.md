# 앱 콘텐츠

대표 에셋·챌린지 샘플은 Codex가 PDF 예시를 참고해 직접 준비한다. 개발용 샘플을 검수된 운영 콘텐츠로 자동 취급하지 않는다.

- catalog/: PDF 예시 장식·캐릭터 정의. 앱용 파일은 miniapp/src/assets 또는 승인 Storage.
- fixtures/: 목표·키워드·조건·비용·모델 임계값·결과 이미지 매핑을 포함한 예시 과제. 실제 제작은 후속 구현 단계.
- policies/: 버전별 점수·보상·추천 정책.
- schedules/: 날짜별 게임/챌린지 편성.

이미지 챌린지 점수/성공 여부는 서버 규칙 기반이며 LLM 채점이 아니다. 선택 문장은 템플릿으로 조합하고 결과 이미지는 검수 profile로 조회한다. 실제 샘플 파일이 아직 없는 상태를 준비 완료로 표현하지 않는다.

별도 콘텐츠 생성기는 사용자가 추후 개발한다. 앱은 승인된 Supabase 데이터 계약을 통해 연결하며 생성기 실행에 의존하지 않는다.
