# AIMI · Light UX를 Figma로 가져오기

최신 Light PDF를 바탕으로 6개 섹션·18개 화면을 생성합니다.
글자, 도형, 벡터 일러스트, 버튼 인스턴스는 편집 가능한 레이어입니다.
PDF나 화면 전체를 이미지로 붙여 넣는 방식이 아닙니다.

## 실행 — Figma 데스크톱 앱에서 한 번

1. ZIP을 압축 해제합니다.
2. Figma **데스크톱 앱**에서 AIMI Design 파일을 엽니다. 빈 Design 파일도 됩니다.
3. Figma 메뉴 → **Plugins → Development → Import plugin from manifest…**를 선택합니다.
4. 압축 해제한 폴더의 **manifest.json**을 선택합니다.
5. **Plugins → Development → AIMI · Light UX Importer**를 실행합니다.
6. **18개 화면 가져오기**를 누르고 완료 문구가 나올 때까지 기다립니다.
7. **Share → 동료 이메일 → Can edit → Invite**로 공동 편집 권한을 부여합니다.

생성한 AIMI 파일: https://www.figma.com/design/sdnkOEQLT9IjxFaTcCVQjq

계정의 Figma MCP 호출 한도 때문에 원격으로 화면을 넣지는 못했습니다.
위 파일에는 준비용 버튼·토큰만 있습니다. 플러그인을 실행해야 18개 화면이 생성됩니다.
이 개발용 플러그인은 MCP를 사용하지 않으며 외부 서버로 데이터를 보내지 않습니다.
플러그인 실행 후 생성된 Figma 파일은 웹에서도 동료와 공동 편집할 수 있습니다.

## 포함 범위

- 홈, 질문 입력, 개선안, 확장 예시
- 모델 추천, 모델 상세
- 길 건너기, Temple Run형, 크롬 다이노형, 게임 종료
- 키워드 선택, 조합 확인, 챌린지 성공/실패
- 정원, 정원 상점, 캐릭터 상점, 소셜
- 공통 색상·간격 변수, 재사용 가능한 버튼, 카드 내부 오토레이아웃
- 챌린지 팝업 배경은 조합 화면 레이어를 복제한 뒤 블러를 적용합니다.

## 최신 PDF 수정 반영 — 2026-11-08 · v13

- 밝은 연두색 Light 배경과 동일한 밝기의 팝업 블러 배경을 적용했습니다. 어두운 딤은 제거했습니다.
- 정원 예시는 안쪽 바닥 상자 없이 불투명한 진한 초록색 단색입니다.
- 소셜 문구: 코드 복사 · 코드로 친구 추가 · 미니앱 초대.
- 홈 출석·팁 팝업도 내부 16px, 관련 문구 8px, 버튼 앞 24px 규칙을 적용합니다.

- 공통 여백: 좌우 24px, 제목/입력 뒤 16px, 설명→목록 12px, 카드 간 8px, 섹션 간 24px.
- 개선안·확장 예시는 상자 없는 텍스트 탭과 짧은 밑줄로 표시합니다.
- 개선 문장 상자 우측 하단에 연필·복사 아이콘을 표시합니다.
- 모델 추천의 직접 입력/개선문 가져오기 상자와 상세 하단 버튼을 제거했습니다.
- 제조사는 행 우측에 표시하며 모델명과 함께 세로 중앙에 정렬합니다. 추천 모델의 제조사명 오른쪽에는 '추천'을 별도로 표시합니다.
- 모델 상세의 Light·공개 지표 배지는 제거하고 출처와 100토큰당 USD 가격 기준을 하단에 표시합니다.
- 모델 상세는 종합 성능·속도·가격, 질문 관련 벤치마크, 하단 출처·측정 조건 순서입니다. 예시 모델의 종합 지수는 N/A이며 IFBench 31.5%, AA-LCR 32.0%는 2026-11-08 확인한 OpenRouter의 Artificial Analysis 공개 점수입니다.
- 게임 화면은 전체 화면으로 구성하고 종료 시 재시도/이미지 챌린지 도전 버튼을 표시합니다.
- 게임 결과·챌린지 성공·실패 팝업의 위치와 크기를 통일했습니다.
- 챌린지 팝업의 뒤쪽은 실제 조합 화면 레이어 복제본에 블러를 적용합니다.
- 게임 종료 팝업도 실제 게임 화면 복제본에 같은 블러를 적용합니다.
- 캐릭터 상점 하단 구매 버튼과 소셜 하단 친구 추가·초대 버튼은 제거했습니다.

## 참고

- 원격 Figma에서 실행·시각 검증은 호출 한도로 완료하지 못했습니다. 실제 가져오기 후 확인이 필요합니다.
- 게임 일러스트와 일부 아이콘은 원본과 맞추기 위해 고정 좌표로 구성됩니다.
- TDS 원격 컴포넌트를 연결한 파일은 아닙니다. 확인한 규격과 원본 SVG를 사용한 로컬 편집본입니다.
- Figma 수정은 기존 PDF에 자동으로 반영되지 않습니다. 이후에는 Figma를 공동 수정 원본으로 사용하세요.
- 이번 버전은 `AIMI · Light UX · 2026-11-08 · v13` 페이지에 생성됩니다. 이전 버전 페이지는 보존됩니다.
- 같은 버전을 다시 실행하면 기존 v13 페이지로 이동합니다. 다시 생성하려면 해당 페이지 이름을 바꾸거나 삭제한 뒤 실행하세요.
