# AIMI Light 디자인 양식

기준: 2026-11-08 Light PDF v13. 화면은 기준 PDF를 따른다. 이 문서와 tokens.json, src/tokens.css는 새 구현의 수치 기준이다. 현재 홈은 CSS 미리보기이며 공식 TDS 컴포넌트 연결 전이다.

## 화면·레이아웃

- 디자인 캔버스 375×812 논리 px. 앱은 반응형이며 viewport 높이를 고정하지 않는다.
- 일반 콘텐츠 좌우 24px. 노치·네이티브 바·키보드 안전 영역은 실제 환경에서 처리.
- 목업 테두리, 9:41, 배터리, 홈 인디케이터를 웹 콘텐츠에 그리지 않는다.
- 공식 SDK 상단 내비게이션을 사용, 자체 뒤로가기·닫기를 중복 표시하지 않는다.
- 탭은 홈/미션/정원/마이, 플로팅 형태. 현재 홈은 디자인 대체 구현이며 공식 형태에 대한 실기기 검증 필요.
- 게임은 화면 전체. 하단 조작 설명 상자 없음.
- 긴 화면은 세로 스크롤, 하단 탭·CTA가 마지막 콘텐츠를 가리지 않도록 공간 확보.

## 공통 간격

| 토큰 | px | 규칙 |
|---|---:|---|
| space-1 | 4 | 보조 라벨 |
| peer | 8 | 동급 카드, 소제목→설명, 관련 문구 |
| copy-list | 12 | 설명→관련 목록 |
| content | 16 | 페이지 제목→첫 콘텐츠, 입력→결과 |
| section | 24 | 기능 묶음 사이, 팝업 본문→주 CTA |
| page-margin | 24 | 일반 화면 좌우 |
| card-padding | 16 | 카드·팝업 내부 |
| button-height | 56 | 주 CTA |
| radius-button | 16 | 주 CTA 모서리 |
| radius-card | 20 | 일반 카드 기본값 |

간격은 글자 baseline이 아닌 텍스트 line box 끝에서 계산한다. 모든 화면과 홈 출석·팁 팝업에 동일하게 적용. 화면 압축을 위해 임의 여백을 넣거나 없애지 않는다.

전체 화면은 부드러운 연두 배경 효과. PDF와 CSS 그라데이션 렌더러 차이가 있으므로 실제 화면에서 조정한다. 정원 예시는 그라데이션·투명도 없이 단색, 진한 안쪽 바닥 상자 추가 금지. 정원 제목은 흰색. EP는 금색 코인이 아닌 녹색 계열 잔액 표시.

## 폰트·타이포그래피

- Figma 전달본: Noto Sans KR Regular/Medium/Bold. 원격 TDS 라이브러리 연결 아님.
- 실제 앱: 호스트·TDS가 제공하는 폰트를 우선 사용. Toss Product Sans 파일을 임의 복사·배포하지 않음.
- 로컬 fallback: -apple-system, BlinkMacSystemFont, Apple SD Gothic Neo, Noto Sans KR, sans-serif.
- 페이지 제목 22px / 1.3, 소제목 17~18px / 1.3, 본문 15px / 1.4~1.5, 설명 13~14px, 보조 라벨 11~12px, 버튼 17px.
- 클릭 대상은 글자 크기와 별개로 충분한 영역. 키워드도 최소 44px 목표 영역 확보.

## 컴포넌트별 기준

- 홈: AIMI·EP 우상단, 오늘 게임 카드·남은 횟수·최고 점수, 출석·팁, 세 기능 진입.
- 개선기: 상자 없는 텍스트 탭+밑줄, 편집·복사는 결과 우하단 작은 아이콘. 동작 영역은 충분히 확보.
- 추천: 입력문 옆 원형 전송, 아래 추천 텍스트. 등급 선택→하단 시트. 모델명 왼쪽·제조사 오른쪽·세로 중앙. 추천 표시는 제조사 옆.
- 모델 상세: 종합 성능·속도·입출력 100토큰당 USD·관련 평가 2~3개·출처/갱신일. 임의 적합도·요청별 예상 총비용 없음.
- 키워드: 상자·분류·개별 가격 없는 텍스트 선택. 선택 색/밑줄+aria-pressed. 조합 확인에서는 선택 칩·순서 변경 제공.
- 팝업: 게임 종료/챌린지 성공/실패 위치·기본 폭 일치. 실제 화면 블러, 어두운 딤 없음. ESC·닫기·초점 복귀·읽기 순서 지원.
- 정원: 한 캐릭터, 우하단 편집 연필. 두 상점 진입 정사각형, 아래 소셜. 상점 상품 2열.
- 소셜: 내 코드 / 코드 복사 · 코드로 친구 추가 · 미니앱 초대. 자체 친구 그래프.

## 공식 구현과 목업 구분

Figma ZIP과 PDF는 편집·검토 기준이다. 가져오기 결과 자체가 반응형 앱이나 게임 코드가 되는 것은 아니다. 공식 TDS 적용은 설치된 SDK·컴포넌트 API 확인 후 진행하며 디자인 목표와 검수 요구가 충돌하면 공식 요구를 확인해 조정한다.
