# 키워드 퍼즐 v4 — 조합별 결과·개수 힌트

2026-11-11 최신 사용자 지시. v3의 첫 실패 정답 수/두 번째 실패 오답 팝업은 폐기한다. 게임 예산(오늘 최고50+점수, 최대150), 제출30예산, EP 정책은 유지한다.

## 결과 표시

제출한 조합마다 왼쪽에 선택 키워드만으로 구성한 요청 문장을, 오른쪽에 일치율과 맞은/미포함 키워드를 표시한다. 추가 LLM 호출이나 이미지 생성은 없다. 범용 문장 템플릿은 선택한 후보의 공개 문장 절과 레이블만 사용하며 정답 집합/원문을 조회하지 않는다. 충돌하는 선택도 임의로 삭제·수정하지 않는다.

- 모두 맞음: 모든 키워드를 맞혔어요.
- 선택한 키워드는 모두 맞지만 누락 있음: 맞았지만 더 찾으세요.
- 맞은 키워드가0개: 키워드가 아예 포함 안 돼요.
- 정답/오답 혼합: 포함되지 않은 키워드가 있어요.

실패 팝업을 띄우지 않는다. 결과는 선택/수정 이후에도 과거 조합 문장 그대로 서버에 남고 재접속 시 복원한다. 정답 전체/원문/작성 팁은 성공 또는 남은 예산상 추가 도전 불가능한 최종 실패 시에만 표시한다. 기존 버전 기록은 저장된 응답을 보존하며 새 구절별 판정을 꾸며 넣지 않는다.

## 개수 힌트

정답 개수는 실패 횟수만으로 자동 공개하지 않는다. 15예산으로 하루 문제당1회 구매한다. 구매는 제출이 아니며 attemptsUsed를 늘리지 않는다. challengeSpent에는 포함된다. 구매 후에도30예산을 남겨야 하므로 잔여45예산 이상에서만 구매할 수 있다.

같은 요청 재전송/서로 다른 중복 구매 요청도 사용자 거래 잠금+멱등 기록+구매 플래그로1회만 과금한다. 닫힌 챌린지/게임 미완료/날짜·버전 불일치/예산 부족은 과금하지 않는다. 이전 v3에서 이미 정답 수가 공개된 진행은 무료로 표시를 유지하며 재과금하지 않는다.

첫 예산 지출(힌트 또는 제출) 때 게임 획득 예산을 고정한다. 성공 보너스도 힌트와 모든 제출의 실제 누적 지출을 반영한 남은 예산 기준이다. 지갑 EP를 차감하는 기능이 아니다.

명시적 answerCount와 누락 개수는 구매 또는 종료 전 API에 포함하지 않는다. 단, 맞은 키워드와 정확한 집합 일치율을 제공하므로 사용자가 수학적으로 총개수를 추론할 수 있다. 개수 힌트는 직접 수치 표시를 위한 편의 기능이며 추론을 방지하는 보안 장벽이 아니다.

## 운영 경계

현재 이미지10개는 Supabase의 미검수 preview 데이터다. 이번 변경은 승인 상태를 바꾸지 않는다. JSON 상태에 힌트 구매 플래그를 추가하므로 새 DDL 없이 기존 prototype_states를 사용한다. 활성 preview release의 rule_version만 v4로 갱신한다. 생성기 원본 CONTRACT.md v2와 v3 문서는 과거 기록이며 최신 앱 동작은 이 문서를 우선한다.

## 게임에서 챌린지로 전환 (2026-11-11 확정)

당일 챌린지 첫 제출(attemptsUsed>0)부터 남은 게임 횟수와 무관하게 게임을 종료한다. 다시 게임으로 예산/EP를 추가할 수 없다. 화면 진입만으로 잠그지 않으며, 제출하지 않은 키워드 편집 중에는 게임 가능. 이미 정산된 게임 결과는 재조회 가능하나 미정산 activePlay를 재개/완료해 예산을 늘릴 수 없다. 다음 한국 날짜에는 새 daily 규칙을 적용한다.
