# 비게임 출시 준비 완료 기준

기준: 2026-11-13. 공식 정책은 TOSS_NONGAME_RELEASE_AUDIT_20261113.md의 출처와94개 대응표를 따른다. 이 문서는 goal의 판정 계약이며 체크리스트를 모두 코드로 확인했다고 실제 출시로 바꾸지 않는다.

## Gate 1 — 구현·번들 준비

- AI 사용 전 인라인 고지, 개선안/확장안·추천 결과·생성 이미지·학습 팁 표시가 보인다.
- 두 버튼 팝업은 왼쪽 닫기/오른쪽 실행. 닫기로 구매·보상을 자동 실행하지 않는다. 처리 중에도 나갈 수 있고 거래는 서버에서 중복 방지한다.
- 네이티브 뒤로가기/닫기와 자체UI 중복 없음. 요청 대기 중 뒤로가기가 전역 잠금에 막히지 않는다. 보상은 창을 닫아도 소멸하지 않는다.
- 중요한 로딩/오류/빈 상태, 안전 영역,320~480px 줄바꿈·터치·스크롤을 확인한다. 폰트·PDF 디자인은 필수 조정 외 유지한다.
- 적절한 단위/DB/브라우저 검증, 웹/토스 빌드 성공. 실제 .ait의manifest/라우트/고지/라벨/테스트UI/비밀값을 검사하고 해시를 기록한다.

## Gate 2 — 운영 연결 준비

- 기존 회원·지갑을 보존하며 운영 migration0008 적용. 제한된API DB역할 권한 확인.
- 같은 콘솔 앱의 mTLS 인증서를 Render Secret Files에 저장하고 기존 경로env를 연결한다. 사용자가2026-11-13 직접 등록하겠다고 지정했으므로 에이전트는 인증서/환경변수를 변경하지 않는다. 비밀은Git/번들/보고서에 포함하지 않는다.
- Render의 배포 커밋이 검증 소스와 일치하고 health/ready가 정상이다. 유효하지 않은 인증코드로mTLS서버연결/오류처리를 확인하며 사용자를 임의로 생성하지 않는다.
- 승인된10일 콘텐츠·팁 일정과 API한도·실패 재시도 경계를 확인한다. Vercel 데모 계정/48시간AI제한은 유지한다.
- 되돌릴 API 커밋·migration의전진호환성·설정복구 위치를 기록한다. 파괴적인DB다운마이그레이션은 하지 않는다.

Gate1·2 완료는 ‘구현·운영 연결 준비 완료’다. 실제토스의 유효 SDK코드가 없으면 개인 인증 성공은 미검증으로 표시한다.

## Gate 3 — 제출·실기기·심사

- 콘솔 브랜드/로고/기능소개/스킴/고객문의/필수고지와 개인정보처리정책 확정.
- 새QR로 iOS·Android의 시작/복귀/2사용자·친구/안전영역·키보드/핀치/실패·이탈/2초내UI반응 검증.
- 앱이름이 아니라 실제 미니게임/보상/학습도구 구성을 토스에 제시해 비게임 분류 승인 확인.
- 필요한 심사 승인 후 운영 공개까지 확인해야 ‘출시 완료’다.

콘솔 접근·실제기기·심사 증거가 없는 상태는 Gate3 대기다. 계정 정보/문의처를 임의로 만들어 채우지 않는다. 외부 항목이 대기해도 가능한 구현·테스트·운영 준비는 계속한다.
