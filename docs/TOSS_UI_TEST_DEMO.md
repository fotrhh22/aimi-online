# 토스 UI 테스트 전용 계정

2026-11-11. 정식 토스 로그인 코드는 유지하면서 별도 테스트 빌드/데모 저장소를 추가했다.

## 사용

1. `npm run ait:build:test`로 생성한 `output/releases/toss-ui-test/AIMI_UI_TEST_ONLY.ait`를 콘솔에 새로 업로드한다.
2. 새 테스트 QR로 열고 **테스트로 시작하기**를 누른다. 토스 로그인/mTLS 없이 공유 테스트 계정을 이용한다.
3. 홈 또는 계정 화면의 **테스트 초기화**로125EP·기본 보유품·정원·게임·챌린지·예시 친구를 복원한다.
4. 다른 접속자도 같은 상태를 공유한다. 누군가 초기화하면 기존 세션은 다시 테스트로 시작해야 한다.

## 격리

- Render `ENABLE_TEST_DEMO=true`일 때만 `/demo/*` 등록. 기본값은 비활성.
- 기존 `/auth/toss`, `/v1` 운영 인증은 그대로. 데모 토큰은 운영 API에서 거부된다.
- 모든 상태/세션 epoch/AI 사용량은 `aimi.test_demo_stores`에 저장한다. 실제 users/ep_wallets/ep_ledger는 쓰지 않는다.
- fixed demo player 및 예시 친구만 접근 가능. 브라우저가 arbitrary userId/잔액을 지정하지 못한다.
- reset 시 epoch를 교체해 이전 요청·게임·AI 응답이 새 상태를 쓰지 못하게 한다. 만료된 이전 응답으로 클라이언트의 새 토큰을 삭제하지 않는다.
- 실사용자 데이터/민감한 프롬프트를 이 공유 테스트 계정에 넣지 않는다. 계정 탈퇴는 운영 계정을 건드리지 않고 초기화 안내로 거부한다.

## AI

- 실제 Gemini 연결을 기존 서버 키로 사용한다. fixture로 자동 전환하지 않는다.
- 전체 공유 계정에서 **최근60분20회**, 최초 테스트 세션부터 **48시간**. DB가 판정하며 초기화·새로고침·Render 재시작으로 연장되지 않는다.
- 데모는 기존 일일5회 제한 대신 시간당 공통 제한을 사용한다. 운영 계정의 기존 기능별 일일 제한은 유지한다.
- 실행한 외부 요청의 실패도 한도에 포함한다. 캐시/탭 전환/모델 목록/규칙 판정은 외부 호출하지 않으므로 추가 소모 없음.
- 기간 종료 후 Gemini 요청만 거부한다. 게임·정원 등은 계속 테스트 가능.
- 홈 테스트 바에 최근1시간 사용량/한도/만료 상태를 표시한다.

## 빌드

- 정식 명령 `npm run ait:build`: 기존 토스 로그인. 기본 빌드에는 ‘테스트로 시작하기’가 포함되지 않는다.
- 테스트 명령 `npm run ait:build:test`: VITE_TEST_DEMO/AIMI_TEST_BUILD를 해당 자식 프로세스에서만 켜고 명확한 테스트 파일명으로 복사한다.
- 실제 Render API 주소를 테스트 빌드에서 고정. 테스트 플래그 없이 정상 브라우저/정식 번들이 데모 세션을 자동 선택하지 않는다.

## DB·환경변수

- migration `202611110007_test_demo.sql`: 데모 전용 테이블, PUBLIC/anon/authenticated 접근 차단, aimi_api 권한만 허용.
- 새 변수는 `ENABLE_TEST_DEMO=true` 하나. Render에 반영. 새 DB/Gemini 키 또는 토스 인증서는 이 테스트 경로에 불필요.
- 운영 인증서/토스 로그인 설정은 여전히 정식 사용자 경로에 필요하다.

## 검증

단위 테스트: 서명·범위가 다른 토큰 거부, 초기 상태, 시간당/48시간 경계.
실제 DB 통합 테스트: 임시 데모 행 사용, 동시20회 예약/21회 거부, 초기화 후 이전 세션 거부,125EP 복원, 호출 카운터/종료 시각 보존, 운영 사용자 수 불변. 임시 행 삭제.
일반 빌드에서 테스트 진입 문구가 없는지 별도 확인. 실제 토스 SDK 터치/안전영역/닫기는 사용자가 새 QR에서 확인한다.
