# 고객 문의·개인정보처리방침 준비 방안 · 2026-11-13

현재 고객 문의 이메일/확정 개인정보처리방침 URL은 없다. 임의 주소를 등록하거나 미완성 정책을 출시용으로 공개하지 않는다.

## 권장 구성과 실행 순서

1. 사용자가 실제 수신·답장 가능한 AIMI 전용 이메일을 만든다. 기존 메일 별칭을 쓸 수 있지만 실제 수신 테스트가 먼저다. 개인정보·계정삭제 문의도 같은 창구에서 받는다. 운영자/담당자와 문의 처리 기한은 실제 운영 가능한 범위로 정한다.
2. `docs/legal/PRIVACY_DRAFT.md`의 미확정 항목을 채운다. 이메일, 운영자, 보유/파기, Render/Supabase/Google의 실제 계약·처리 위치·백업·로그 기간을 확인한다.
3. 확정본은 로그인 없이 열리는 HTTPS 정적 페이지로 게시한다. 기존 공개 GitHub 저장소를 이용한 GitHub Pages를 권장한다. 예시 후보 `https://fotrhh22.github.io/aimi-online/privacy.html`은 아직 게시되지 않은 제안 주소다. Vercel 데모를 복구할 필요는 없다.
4. GitHub Pages의 Pages 설정·HTML 게시 후 휴대폰에서 외부 로그인 없이 본문이 열리는지 확인한다. 콘솔에는 검증된 실제 URL과 이메일을 입력한다. 앱 계정관리에도 같은 정책/문의 안내를 연결한다. 지금은 미확정 주소를 앱에 넣지 않는다.
5. 최종 버전·시행일·이전 정책 이력을 보관하고, 실제 데이터 처리와 정책이 일치하는지 출시 전에 대조한다.

## 실제 구현에서 반영할 내용

- 토스 SDK 인증코드는 서버에서 일회성 교환한다. 원본anonKey 대신 HMAC 식별값과 내부회원UUID를 사용한다. 동의창이 없다고 개인정보 처리가 없다는 뜻은 아니다.
- 닉네임/친구코드/친구관계/정원/아이템/EP/게임·챌린지기록을 저장한다. 정원은 수락한 친구에게만 보인다. 계정삭제 API와 데이터 연결을 설명한다.
- 질문 개선·업무 분석을 위해 입력 텍스트와 시스템 지침을 Google Gemini API로 전송한다. 닉네임·친구코드·세션토큰을 AI 요청에 자동 첨부하지 않는다. 개선 결과·업무 요약에는 입력 내용이 반영될 수 있다.
- AI결과/중복요청 응답은 현재24시간 기준 정리 코드가 있지만 이것만으로 전체 데이터·백업·Google보유기간을24시간으로 표시하지 않는다. 사용자기록/보안로그/백업은 각각 실제 기간을 확정한다.
- OpenRouter는 사전 콘텐츠 제작용이다. 앱 내 실시간 추천이 사용자 입력을 추천 대상 모델 공급사 전부에 보내는 구조가 아니다.
- Vercel 개인데모는 종료됐다. 과거 테스트 계정 자료의 보유/삭제 방침도 별도로 결정한다. 이번 작업에서는 기존DB자료를 삭제하지 않았다.

## Google 데이터 이용 조건 확인

공식 Gemini API 약관은 무과금 서비스와 결제계정이 연결된 서비스를 구분한다. 무과금 서비스의 입력/응답은 제품 개선에 사용될 수 있으며 민감·기밀·개인정보를 제출하지 말라고 안내한다. 결제계정 연결 여부를 확인하지 않고 ‘학습 미사용/보관 없음’을 약속하면 안 된다. 무료 사용량으로 호출된다는 말만으로 약관 적용 종류를 확정하지 않는다.

공식 자료: https://aistudio.google.com/docs/terms (2026-11-13 확인), https://www.privacy.go.kr/ (최신 작성지침 확인용 공식 포털).

이 문서는 구현·게시 준비안이다. 국외이전/처리위탁/제3자제공 해당 여부와 필요한 고지·동의는 실제 계약과 데이터 흐름으로 확정하며, 아직 출시용 최종 처리방침으로 승인한 상태가 아니다.
