# 정원 에셋·캐릭터 확장 후보

2026-11-09. 아래30종 아이템·10종 캐릭터는 기존 PDF 스타일을 참고한 독창적인 SVG로 제작하고 상점에 등록했다. 가격은 개발용 초안이며 최종 경제 밸런스 확정값은 아니다. 기존 PDF의 화분·꽃·울타리·벤치와 새싹·토끼·곰은 유지하며 아래 후보는 별도로30종+10종이다. 총합30/10으로 운영하려면 기존 품목 수만큼 후보를 줄인다.

## 실제 제작·저장 결과

- 원본/상점/게임용: `apps/miniapp/public/content/<asset-id>.svg`. 기존8종과 같은 위치에 새40종을 추가했다. 기존 파일은 덮어쓰지 않는다.
- 정원 배치용: `apps/miniapp/public/content/garden/<item-id>.svg`. 실제 그림 경계에2px 여유를 둔 viewBox로 생성한다. 모든 새 아이템의 경계는 Resvg로 계산하고 공유 계약으로 출력한다.
- 제작 소스: `tools/assets/build-expansion.mjs`. 출력 메타데이터: `packages/contracts/src/content/asset-expansion.ts`. 공통 크기/앵커/경계는 garden.ts를 재사용한다.
- 전체 미리보기: `output/assets/shop-v1/contact-sheet.png`/`.svg`. 개별 PNG와 manifest.json도 같은 폴더에 있다. PNG는 검수용이며 앱에서는 SVG를 사용한다.
- 재생성: `npm run assets:build`. 오프라인 렌더/경계 검사: `npm run assets:check`. 기존 build-fixtures.py는 기존 PDF 품목만 재생성하며 신규 파일을 삭제하지 않는다.
- 기존4종씩 포함해 상점은 아이템34종/캐릭터14종이다. 구매/수량/소유/선택/게임 캐릭터 로더는 기존 공통 흐름을 사용한다. 신규 캐릭터는 현재 정면 단일SVG+공통 변형 애니메이션으로 동작한다. 별도 뒷모습/프레임 애니메이션 제작은 아직 하지 않았다.
- 외부 이미지·브랜드 캐릭터·게임 그래픽을 복사하지 않았다. 원본 도형은 프로젝트에서 직접 작성했다. SVG 렌더용 개발 도구 @resvg/resvg-js는 MPL-2.0이며 앱 런타임에는 포함하지 않는다.
-40종 오프라인 렌더/30종 그림 경계·이동 경계 검사, 신상품 전부 구매/배치/캐릭터 저장 단위 검증 통과. 실제 브라우저 검증은 사용자 요청으로 생략한다.

아래 제작 후보/규격은 구현 계획의 이력을 포함한다.

## 추가 캐릭터10종

병아리, 오리, 고양이, 강아지, 햄스터, 다람쥐, 여우, 개구리, 너구리, 고슴도치.

기존 캐릭터와 같은 둥근 비율·단순 얼굴·파스텔 색·짧은 팔다리를 사용한다. 여우/너구리처럼 비슷한 실루엣은 귀/꼬리/배색으로 구분하고 색만 바꾼 복제 상품을 기본으로 삼지 않는다. 기존 원작 캐릭터나 그래픽은 복제하지 않는다.

## 제작 규격·검수

- 정원 아이템: 투명 배경, 같은 시점과 그림자 방향, 외곽 장식 최소화. 상품 썸네일과 정원 배치용 타이트한 그림 경계/하단 중앙 앵커를 함께 제공한다. 기존 SVG 체계와 동일하게 벡터로 만들거나, 래스터 원본을 사용하면 투명 PNG/WebP와 실제 그림 경계 메타데이터를 제공한다.
- 각 아이템의 asset ID·source·라이선스·그림 경계·정원 상대 폭·앵커·기본 그리기 순서를 등록한다. GARDEN_ITEM_GEOMETRY와 API 경계 검증이 같은 크기를 사용한다. 임의의 큰 빈 캔버스를 드래그 경계로 쓰지 않는다. 선택 경계와 최소44px 터치 영역은 별개다.
- 작은 소품 폭6~12%, 중간 아이템12~22%, 나무/시설22~34%를 제작 시작값으로 삼아320px에서 확인한다. 상품별 고정 위치 제한은 없다. 거대한 배경/울타리 전체 프레임은 별도 상품 유형을 설계하기 전 제외한다.
- 캐릭터: 정원 정면 기본1장과 길 건너기/러너용 뒷모습을 포함한다. 달리기·점프·착지·충돌은 현재 공통 변형 애니메이션으로 우선 연결한다. 정교한 프레임 애니메이션을 제작하면 모든 캐릭터에 동일 상태/타이밍 계약을 적용한다. 현재 로더는 단일SVG 기반이므로 여러 시점/스프라이트 추가는 로더 확장 후 가능하다.
- 캐릭터의 실제 충돌 크기는 외형에 따라 유리해지지 않게 공통으로 유지한다. 큰 꼬리/귀는 장식 영역으로 취급한다.
- 카드에서 이름11px·수량12px·상태10px를 분리하고 긴 문구는 줄바꿈하며 카드 높이를 자동 확장한다. 실제 장면·상점 썸네일·수집함·선택 테두리를 모두 검수한다.
- AI 생성은 후보 생산 수단이며 승인 없이 자동 발행하지 않는다. 배경/스타일 일관성·중복·경계·해상도·상업 이용 조건을 검수하고 보정한다. 별도 생성기는 추후 개발 범위다.

## 반영 순서

대표5개 아이템+2개 캐릭터 →320/375/480px 조합 검수 →나머지 제작 →메타데이터/상품/소유·수량 계약 등록 →구매·드래그·저장·친구 방문·세 게임 확인. 신규 아트40개를 생성 완료했다고 표현하지 않는다.
