# 키워드 퍼즐 v3 — 2026-11-11 최신 사용자 지시

생성기 CONTRACT.md v2의 후보/정답 집합/정답 비공개 규칙을 기반으로 하되, 이후 사용자 요청으로 아래를 변경했다. 생성기 원본 계약은 과거 버전으로 보존하며 앱은 이 문서를 우선한다.

- 제출1회30예산. 키워드 수/순서/모델 선택에 따른 추가 비용 없음. 모델 선택 UI 없음. 30은 수치 미지정 상태에서 정한 개발 기본값이며 공용 PUZZLE_ATTEMPT_COST 상수로 관리한다.
- 게임으로 획득한 오늘 최고 기록 예산(50+점수, 최대150)을 첫 유효 제출 시 고정한다. 이후 제출마다30을 누적 차감한다. 도중 게임으로 예산을 다시 늘려 정답 공개 후 재도전할 수 없다. 50예산1회/90예산3회/150예산5회.
- 잘못된 ID/빈 선택/중복 ID/콘텐츠 버전 불일치/시스템 오류는 횟수와 예산을 소모하지 않는다. 같은 멱등 요청 재전송도 추가 차감하지 않는다.
- 첫 실패: 정답 개수 팝업. 두 번째 실패부터 선택한 오답·누락 정답 수 팝업. 선택한 오답이 없고 누락만 있으면 ‘개수가 부족해요’. 미선택 정답 ID는 종료 전 비공개다.
- 팝업에 ‘다시 시도하기 / 나가기’. 닫기/나가기는 추가 비용을 내지 않으며 현재 시도의 차감을 취소하지 않는다.
- 실패한 제출 후 남은 예산<30이면 최종 ‘챌린지 실패’. 성공과 동일하게 정답·원문(하이라이트)·작성 팁을 표시한다. 종료 화면에서 다시 시도하기는 제공하지 않는다.
- 성공은 선택 집합과 정답 집합이 정확히 같을 때만. 일치율은 floor(1000*교집합/합집합)/10. 순서와 모델 비용으로 통과 기준을 낮추지 않는다.
- 기존 EP 보상 정책은 유지하며 성공 보너스는 실제 남은 예산 기준이다. 예산 차감은 지갑 EP 차감이 아니다.
