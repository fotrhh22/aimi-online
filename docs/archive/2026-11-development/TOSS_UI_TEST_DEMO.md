# 토스 공유 UI 테스트 모드 — 과거 기록

이 문서는 출시 전 테스트 이력의 기존 링크를 보존한다. **현재 이용·배포 경로는 앱인토스 정식 미니앱**이며, 테스트 계정·접속 코드 발급·Vercel Import/환경변수 설정을 현재 절차로 안내하지 않는다.

출시 전 웹 시연은 공유 계정에서 개인 코드 방식으로 확장됐고 2026-11-13 종료했다. 토스 공유 UI 테스트 역시 실제 사용자용 익명 인증과 구분하는 과거 테스트 모드다. 운영 계정에는 개발 초기 재화·테스트 친구·테스트 초기화를 적용하지 않는다.

짧은 이력은 [운영 이력](../RELEASE_HISTORY.md), 현재 구성과 실행 방법은 [README](../../../README.md) 및 [배포 안내](../../current/DEPLOYMENT.md)를 참고한다. 상세한 당시 구현은 Git 이력에서 조회할 수 있다. 이 문서를 정리하면서 데모 기록·운영 DB·환경변수·프로젝트를 삭제하거나 변경하지 않았다.
