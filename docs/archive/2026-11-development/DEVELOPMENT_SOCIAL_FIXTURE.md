# 개발용 소셜 친구

2026-11-09. 로컬 prototype-server의 개발 로그인에서만 테스트 친구1명을 연결한다. 운영/Render/Toss 로그인에는 적용하지 않는다.

- 이름: 모모 · 테스트 친구. 캐릭터: 살구 여우. 오늘 챌린지 성공은 UI 확인용 합성 상태이며 실제 보상을 지급하지 않는다.
- 공개 정원: 사과나무·표지판·당근 텃밭·버섯·조명5개 배치. 방문은 읽기 전용이다.
- 첫 개발 로그인에서 상호 친구 관계를 생성한다. 동일 계정 재로그인으로 중복 추가하지 않으며 삭제/차단한 친구를 자동 복구하지 않는다. 기본 메모리 API 재시작 시 데이터가 초기화되면 다시 생성된다.
- UI 경로: 개발 로그인→소셜→모모 · 테스트 친구 카드를 누르면 바로 정원을 방문한다. 카드 우측 상단 점3개→삭제로 친구 관계를 해제한다.

## 현재 공유 값

|경로|공유 값|
|---|---|
|친구 목록|내부 친구ID, 이름, 선택 캐릭터, 친구 코드, 요청 여부, 오늘 챌린지 성공 여부/표시 상태, 누적 챌린지 성공 횟수|
|정원 방문|이름, 선택 캐릭터, 오늘 챌린지 성공 여부, 누적 챌린지 성공 횟수, 공개 정원(배치 itemId/instanceId/x/y, revision/public 및 호환 slots)|

EP 잔액·전체 보유품·입력 프롬프트/개선 결과·AI 사용량·인증 토큰/키는 이 응답에 포함하지 않는다. 친구가 아니거나 차단/비공개 상태이면 방문은403이다. 정원 편집 권한은 전달하지 않는다. 이 문서는 현재 API 응답 범위를 기록하며 모든 친구에게 계정 전체가 공개된다는 뜻이 아니다.

## 구현과 검증

`apps/api/src/modules/development-friend.ts`는 prototype-server의 `/auth/local`에서만 호출한다. 테스트 계정의 실제 사용자 정보는 사용하지 않는다. 단위 검증은 중복 생성 방지·상호 관계·삭제 후 재생성 방지·친구 목록 개인정보 제외·방문 응답·미친구 접근403을 포함한다.

별도 테스트 서버는 UI5280/API8181에서 신규 상점34/14개와 테스트 친구/방문 정원5개가 실제 API 응답으로 확인됐다. 기존 사용자 서버5180/8081은 임의 종료하지 않았다. 그 서버에서 확인하려면 최신 코드로 개발 서버를 재시작하고 개발 로그인한다. 브라우저 UI 검증은 생략했다.

친구 프로필 팝업은 제거했다. 친구 카드 직접 방문과 우측 점3개 삭제 메뉴를 사용한다. 방문 화면에는 오늘 챌린지 성공/미성공과 누적 성공 횟수를 표시한다. 오늘 상태는 Asia/Seoul 기준이며 누적 횟수는 모든 저장 날짜의 success=true 개수다. 현재 하루1회 성공 정책에 따른다. 차단 UI는 없으며 기존 서버 차단/권한 검증은 유지한다.

삭제 메뉴는 우측 정렬이며 클릭 시 삭제 확인 팝업에서 취소/삭제를 선택한다. 로컬 개발 화면의 `테스트 친구 복구`는 인증 후 `/dev/social/restore`를 호출해 예시 친구만 복구한다. 자동 로그인 시 삭제된 예시를 매번 되살리지는 않는다. 운영 서버에는 이 경로가 등록되지 않는다.
