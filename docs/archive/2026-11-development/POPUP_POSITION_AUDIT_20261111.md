# 팝업 위치 코드 전수 점검 · 2026-11-11

## 원인과 공통 수정

미션/챌린지 화면의 첫 자식이 dialog일 때 `#root .page > :first-child { margin-top: 0 }`가 `.overlay { margin: auto }`를 덮어써 상단으로 이동했다. 첫 자식 간격 규칙에서 dialog를 제외했다.

일반 팝업은 `#root dialog.overlay:not(.sheet)`의 fixed/inset:0/margin:auto로 화면 중앙에 배치하고, 긴 내용은 화면 높이에서 48px를 뺀 최대 높이 내에서 스크롤한다. 이전 result-modal의 top:110px 예외도 중앙 규칙으로 통일했다. 하단 시트는 별도 fixed/inset:auto 0 0 규칙을 보존했다. 최대 너비·border-box로 패딩을 포함해 화면 밖 너비가 생기지 않도록 했다.

## 힌트 UI

작은 전구 아이콘과 ‘개수 힌트’ 이름, 따뜻한 황금빛 배경·짙은 녹색 글자로 힌트 상품처럼 표시한다. 예산15 소모 안내는 유지한다. 확인 팝업은 ‘정답 단어가 몇 개인지 알려드려요’로 설명하고 구매 후 예산과 도전 가능 횟수를 표시한다. 취소/닫기는 구매 API를 호출하지 않는다.

## 팝업 버튼 배치 점검

TSX 구문 트리에서 Modal 17곳을 조사했다. 2버튼 8곳, 1버튼 8곳, 버튼 없는 이미지 갤러리 1곳이다.

기존 세로 배치 5곳: 정원 변경사항 저장, 친구 삭제, 계정 연결 해제, 게임 나가기, 게임 기록 재확인 오류.
기존 가로 배치 3곳: 개수 힌트, 캐릭터 변경, 상점 구매.

모두 공통 grid 규칙으로 통일했다. 두 버튼은 동일 너비 가로 2열, 하나는 전체 너비. 최소 높이 56px에 긴 문구는 줄바꿈하고 높이를 늘린다. 정원 저장의 계속 편집 텍스트는 두 버튼 아래 전체 너비로 유지한다. 힌트는 예산 사용 왼쪽/취소 오른쪽 유지. 일반 페이지와 수량 증감, 선택 목록에는 적용하지 않는다. 타입 검사와 빌드 통과. 브라우저 검증 생략.

## 색상과 버튼 순서 추가 점검

공통 Button 50개 사용 지점을 구문 트리로 수집했다(주요34/보조16). output/qa/button-style-audit-20261111.json에 파일/행/문구/역할을 보관한다. 기본 페이지 CTA는 primary/weak 규칙을 사용하나 다른 질문 다듬기는 별도 원시 버튼과 별도 진한 배경을 쓰고 있었다. 이를 공통 Button weak로 교체했다. 텍스트 링크, 탭, 상품/친구 카드와 선택 목록은 CTA가 아니므로 일괄 배경 변경하지 않는다.

2버튼 팝업8곳의 실행 왼쪽/취소 오른쪽, primary/weak 및 취소 문구를 정적 검증했다. 기존에 역순인 캐릭터 선택/상점 구매/친구 삭제/탈퇴를 DOM 순서부터 수정했다. 게임 종료는 왼쪽 나가기/오른쪽 취소(이어하기), 정원 저장은 왼쪽 저장/오른쪽 취소(편집 유지)로 맞췄다. 저장하지 않고 나가기는 하단 텍스트로 남겼다. 오류 재확인의 취소는 미션으로 복귀하며 본문에 안내한다.

소셜 메뉴는 점3개와 삭제를 한 행에 연속 배치하고 바깥 상자 패딩/테두리를 제거했다. 열린 상태에는 친구 이름과 겹치지 않도록 우측 여유를 확보한다. 타입 검사/빌드 통과. 브라우저 시각 검증은 생략했다.
