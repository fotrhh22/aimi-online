# AIMI 포지셔닝 조사·맵 구축 제안

조사일: 2026-11-09 KST. 공식 서비스 소개/문서에서 공개 기능을 확인했다. 전체 유료 기능·실사용·리텐션을 비교 시험하거나 소비자 인식 설문을 수행한 결과는 아니다. 아래 위치는 제품 구조에 대한 분석 가설이며 시장점유율/학습효과/비용절감 실측 순위가 아니다. 국내 전체 경쟁사를 조사 완료했다는 의미도 아니다.

## 권장 포지셔닝

**AI를 써보지만 원하는 조건을 전달하고 업무에 맞는 모델을 고르는 데 어려움이 있는 일반 사용자를 위한, 매일 짧게 연습하고 정원을 키우는 AI 활용 연습 미니앱.**

진입은 일일 게임/보상, 학습 행동은 조건 선택→결과 피드백→재도전, 실생활 연결은 내 질문 개선→요구 수준/모델 비교, 재방문 이유는 날짜별 콘텐츠·정원 수집·친구 방문이다. 게임 실력이나 정원 수집이 AI 실력을 직접 증명한다고 표현하지 않는다.

브랜드 문구 제안: **AI를 잘 쓰는 감각을, 매일 조금씩 키워요.**

토스는 유통/접근 채널이다. '토스에 있다'만으로 제품 효용이나 지속 이용이 입증되지는 않는다. 먼저 일반 사용자/대학생/초기 직장인 중 무엇이 가장 잘 맞는지 사용성 조사로 좁힌다. 현재는 일반 AI 입문·활용 지원 포지션이며 고급 전문가용 LLM 운영 플랫폼이나 정식 자격 교육과정이 아니다.

## 주 맵: 반복 참여 설계 × 일상 활용 연결

- **X축: 반복 실습을 유도하는 게임·보상·수집 결합 정도.** 단순 사용 빈도/리텐션 수치가 아니다. 반복 도전, 단계, 날짜별 콘텐츠, 보상/수집, 소셜 연결 등 공개된 구조를 확인한다.
- **Y축: 일반 사용자의 일상 AI 활용에 연결하는 정도.** 자기 업무/질문 입력, 작성 개선, 조건 설명, 모델 선택과 비교, 결과를 실제 업무에 가져가는 흐름을 본다. 특정 보안 도전의 기술적 난이도나 모델 자체의 성능 점수가 아니다.

| |반복 참여 설계가 상대적으로 약함|반복 참여 설계가 상대적으로 강함|
|---|---|---|
|일상 활용 지원에 초점|Prompt Cowboy·OpenRouter·Artificial Analysis. 강점이 서로 다르므로 세부 비교는 위 표를 함께 사용|**AIMI 목표 위치:** 일일 연습→내 질문 개선→모델 선택→정원 성장|
|특정 과제/경험에 초점|정보/문서 참고형 자료. 억지로 특정 서비스를 채워 넣지 않음|Lakera Agent Breaker: 보안 목적의 점수·레벨·재도전|

Learn Prompting과 Google 과정은 실습과 실제 업무 프로젝트를 함께 제공하므로 좌측 아래에 몰아넣지 않는다. 두 축에서 중간~상단의 별도 교육군으로 표시한다. 설문/기능 체험 전 임의로0~100 정밀 점수를 부여하지 않는다. 공개 자료에 특정 기능이 보이지 않는 것과 그 기능이 실제 없다는 것은 다르다.

이 맵은 **제품 구조를 설명하는 비교도**다. 소비자가 인식하는 포지셔닝 맵으로 제출하려면 동일한 사용 과제를 경험한 뒤 각 축에 대한 인식 조사가 필요하다. 현재 경쟁 서비스의 리텐션이나 학습 성과를 추정 숫자로 채우지 않는다.

## 현재 AIMI와 목표 AIMI 구분

현재 AIMI는 반복 참여 구조(세 게임·일일 제한·EP·정원/캐릭터·친구)를 구현했다. 그러나 운영 콘텐츠 발행/날짜별 reader, 결과 이미지 완전성, 모델 매핑/성능 근거, 실제 토스 로그인/실기기 인수가 남아 있다. 모델461개 가운데449개의 가격 기반 임시 분류를 성능 등급 완성으로 표현할 수 없다.

따라서 맵에는 **'AIMI 현재: 반복 구조는 구현, 일상 활용 연결은 검증 중'**과 **'AIMI 목표: 매일 연습한 조건을 실제 질문·모델 선택에 활용'**를 구분한다. 목표를 현재 실적처럼 우측 상단에 단일 점으로 표시하지 않는다.

## 보조 맵: 대상 사용자 숙련도 × 주 이용 목적

제품 설명이 복잡해 보이면 두 번째 비교도를 사용한다.

- X축: AI 입문/일반 사용자 ↔ 전문 개발/운영 사용자.
- Y축: AI 사용법을 익히기 ↔ 당장 업무 결과/선택을 해결하기.
- AIMI는 입문/일반 사용자 쪽에서 학습과 실용 지원을 연결하는 위치를 목표로 한다.
- Learn Prompting/Google은 입문부터 확장되는 교육군, Prompt Cowboy는 작성 지원군, OpenRouter/AA는 모델 비교/운영 선택군으로 구분한다. 전문가도 각 서비스를 사용할 수 있으므로 배타적인 사용자 구획으로 표현하지 않는다.

'저렴함↔고성능', '쉽다↔좋다', '토스↔웹', '친환경↔비친환경'을 주 축으로 쓰는 것은 권하지 않는다. 가격/성능은 서비스와 모델이 혼동되고, 토스 여부는 채널이며, AIMI는 탄소/전력을 실측하지 않기 때문이다.

## 차별점이 실제로 이어지려면

1. **도전마다 학습 개념이 남아야 한다.** 수량·대상·관계·스타일의 차이를 결과/피드백으로 설명하고 새 이미지에서도 적용하는지 확인한다. 정해진 단어 정답을 외우는 것과 자유 프롬프트 작성 능력은 다르다.
2. **연습을 내 질문에 연결해야 한다.** 개선기가 추가한 조건을 설명하고 사용자가 최종 문장을 고치거나 가져갈 수 있어야 한다. 챌린지와 개선기가 독립 메뉴인 것만으로 학습 전이를 주장하지 않는다.
3. **모델 추천은 근거를 먼저 확보해야 한다.** 같은 업무량·필수 기능·검증된 품질을 만족하는 후보의 예상비용을 비교한다. 최저가/실제 절감/환경 효과를 보장하지 않는다.
4. **게임은 재방문 동기이면서 진입 장벽이 될 수 있다.** 어렵게 만든 게임이 초보자의 챌린지 진입을 막는지 관찰한다. 게임과 AI 실습의 완료율을 별도로 본다. UI/정책 변경은 이 보고서만으로 실행하지 않는다.
5. **정원은 학습 결과를 기억하게 하는 역할이 필요하다.** EP 획득량만 높이는 대신 어떤 AI 개념을 연습했는지 누적 기록과 연결할지 후속 검토한다. 현재 누적 성공 횟수는 학습 숙련도 점수가 아니다.

## 검증 계획 제안

- 1차 질적 조사: 일반 AI 사용자5~8명에게 AIMI와 비교 서비스의 같은 목적 과제를 경험하게 하고, 어디에 쓰는 서비스인지/다시 올 이유/학습과 게임의 연결을 질문한다. 이 인원으로 시장 전체 선호를 통계적으로 주장하지 않는다.
- 사용 과제: 조건이 빠진 이미지 지시문 고치기, 자신의 실제 질문 개선하기, 제한된 업무 조건에서 모델 후보 선택하기.
- 맵 평정: '반복해서 연습하고 싶은 구조인가', '내 일에 바로 적용할 도움을 받는가'를 같은 척도로 평가하고 서술 이유를 수집한다. 순서 효과를 줄이도록 서비스 노출 순서를 나눈다.
- 제품 지표: 첫 챌린지 도달률/시간, 다른 목표에서 조건 이해·오류 감소, 개선문 수정/복사, 추천 근거 이해, D1/D7 AI 실습 재방문. 정원/게임만 재방문한 사용자와 구분한다.
- 실제 비용 효과: 같은 작업/품질 기준에서 비교 가능한 유료 호출을 측정할 평가 계획이 있어야 한다. 현재 예산/EP/단가 계산만으로 실제 청구액 절감률을 발표하지 않는다.

## 보고/소개에 쓸 문장

AIMI는 **일반 사용자가 짧은 게임과 이미지 도전을 반복하며 AI에 조건을 전달하는 연습을 하고, 자기 질문 개선과 모델 비교로 이어가는 정원형 AI 활용 미니앱**이다. 일일 보상·캐릭터·친구 방문은 반복 참여를 돕도록 설계했다. 학습 효과/습관 형성/비용 절감은 출시 전후 검증할 가설이다.
