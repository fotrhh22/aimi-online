## 유지보수 원칙

실제 수집 항목·보관/삭제·외부 처리와 방침이 일치하는지 데이터 흐름이 바뀔 때 확인한다. Render·Supabase·Google을 사용한다는 사실만으로 운영자의 설명 책임을 대신하거나, 계약상 역할·국가·보유기간을 추정해 쓰지 않는다. 이번 문서 정리로 국외이전/위탁/제3자제공 등의 법률 판단이나 미확인 공급자 계약 조건이 확정됐다고 표시하지 않는다.

개선/분석 요청은 Google Gemini로 전달된다. OpenRouter는 사전 이미지 제작·모델 자료와 구분하며, 추천 대상 공급사 전체에 사용자 입력을 보내는 구조로 설명하지 않는다. 원본 인증코드·세션토큰·서버 비밀값은 문의 로그나 공개 보고서에 남기지 않는다.

외부 정책 사본이 실제로 필요해지면 같은 본문과 시행일을 맞추고, 새 공식 요구를 확인한 뒤 제공한다. 현재 필수 선행 작업처럼 GitHub Pages나 종료된 웹 데모의 새 배포를 요구하지 않는다.

과거 준비·약관 조사 내용은 Git 이력에서 볼 수 있다. 현재 상태는 [구현·운영 상태](../../current/IMPLEMENTATION_STATUS.md), 변경 점검은 [업데이트 점검](../../current/RELEASE_READINESS.md)을 따른다.
