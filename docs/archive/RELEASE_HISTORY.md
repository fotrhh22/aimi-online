최초 출시 전의 상세 계획·오류·점검 결과는 Git 이력에 보존된다. 과거의 ‘출시 대기’, ‘인증 미연결’, ‘콘텐츠 미승인’ 문장을 현재 상태로 인용하지 않는다. 과거 데모 주소나 배포 절차를 현재 이용 안내로 재사용하지 않는다.
