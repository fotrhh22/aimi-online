# 문서 정리 기록 · 2026-11-13

README는 서비스 소개로 축약하고 실행/운영은 current, 초기 계획/조사/종료된 데모는 archive로 분리했다. 예전 루트 문서 경로를 사용하는 에이전트는 docs/README.md에서 현재 문서를 찾는다.

AIMI의 설명용 준비 README 42개는 과거 기록 하나로 합쳤고, 이 중 README만 있던 빈 디렉터리는 정리했다. 코드가 있는 디렉터리는 보존했다. 모델 재생성/테스트 입력은 data/model-sources, 로컬 진단 결과는 output으로 구분했다. 데이터 이동은 원본 바이트를 유지하며 참조 경로만 수정했다.

캠페인의 원래 루트 PDF/Word 5개는 docs/local-reference에 로컬 보관했다. 같은 작업 폴더의 독립 프로젝트는 상위 Git에서 제외하며 실제 프로젝트 폴더를 삭제/이동하지 않았다. 비밀 파일·인증서는 이동/공개하지 않았다.

운영 DB·Render·토스 번들·기존 사용자 기록은 변경하지 않았다. 원래 존재하던 미커밋 소스 수정은 보존했다.
