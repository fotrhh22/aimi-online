# AIMI 뒤로가기·내부 왕복 정책

2026-11-11 로컬 미리보기 반영. 앞선 조사 보고서의 미반영 진단과 구분한다.

## 처리 순서

1. 쓰기 요청 중이면 페이지 이동을 막고 처리 중 안내. API 오류·타임아웃을 포함해 finally에서 해제한다. GET 조회는 이 잠금에 포함하지 않는다.
2. 가장 위에 열린 dialog만 닫는다. 저장 중 닫을 수 없는 dialog는 유지한다.
3. 친구 ⋯ 메뉴 또는 개선문 편집 같은 등록된 하위 상태를 처리한다.
4. 진행 중 게임과 수정된 정원은 기존 일시정지/저장 확인 guard를 실행한다.
5. 공통 parentRoute로 이동한다. 임의의 history.back에 목적지를 맡기지 않는다.

화면 버튼·토스 back callback·브라우저 pop에 공통 정책을 사용한다. 브라우저 앞으로가기는 저장된 index/trail을 복원하며 뒤로가기 정책으로 가로채지 않는다. 팝업/guard/요청 잠금으로 pop을 소비하면 기존 위치로 되돌리고 새 history를 push하지 않는다. 직접 상세 URL 진입은 앱 안에서 돌아갈 entry를 준비한다.

## 페이지별 부모

| 현재 화면 | `<` 목적지 |
|---|---|
| 홈 | 실제 앱에서 closeView, 로컬에서는 종료 호출 대체 |
| 미션 / 정원 / 소셜 | 홈 |
| 게임 중 | 일시정지 후 계속하기/나가기 |
| 게임 저장 중 | 유지 |
| 게임 저장 실패 | 미션, 같은 기록 재확인 경로 유지 |
| 게임 결과 | 홈 |
| 챌린지 선택 | 오늘의 미션 |
| 조합 확인 | 키워드 선택, draft 유지 |
| 도전 결과 | 오늘의 미션 |
| 정답 확인 | 해당 도전 결과 |
| 정원 편집 | 정원. dirty이면 저장/버리기/계속 편집 |
| 정원·캐릭터 상점 | 정원 |
| 친구 정원 | 소셜 |
| 모델 상세 | 챌린지에서 열었으면 홈으로 바로 이동. 추천에서 열었으면 해당 추천 상태로 복귀. 직접 진입이면 추천 |
| 계정 | 계정을 열었던 화면. 직접 진입이면 홈 |
| 프롬프트 개선 | 홈. 편집 중이면 편집 모드만 취소 |
| 모델 추천 | 개선기에서 왔으면 보존된 개선기, 직접 왔으면 홈 |

키워드 선택·문장·예산·결과·정원 보유품을 뒤로가기에서 새로 만들거나 차감하지 않는다. 동일 화면 이동은 무시하며, 탭 전환과 기존 목적지 복귀는 replace한다. 연속 모델 상세는 부모를 모델 상세로 쌓지 않는다.

## 과도한 뒤로가기 감소

| 조사 시나리오 | 적용 후 |
|---|---|
| 탭30회 이동 | 홈까지 `<`1회 |
| 서로 다른 모델 상세12회 이동 | 추천 목록까지1회, 홈까지2회(개선기에서 인계한 경우에는 개선기 복귀 단계가 하나 더 있음) |
| 정원→상점→편집 | 정원까지1회, 홈까지2회. 상점으로 되돌아가지 않음 |
| 같은 챌린지 선택 화면5회 이동 시도 | 중복 entry 없이 미션까지1회, 홈까지2회 |
| 정답·도전 결과→모델 상세 | 최신 사용자 정책에 따라 `<`1회로 홈. 모델 상세의 별도 홈 텍스트 링크는 제거 |
| 인라인 모델 목록·검색·구절 팁 | 단순 펼침 상태를 별도 페이지로 쌓지 않음. 나가려고 목록·검색을 하나씩 닫는 추가 back을 강제하지 않음 |

진행 중 게임·정원 미저장 확인은 재화/작업 보호를 위해 명시적인 계속/나가기 선택을 유지한다. `<` 연타를 확인 승인으로 해석하지 않는다.

## 내부 왕복 상태

개선기·추천은 해당 AI 흐름/모델 상세/계정 왕복 동안 숨긴 main으로 유지한다. 추천 모델군·출력 종류·검색·결과·목록·입력과 개선 결과를 단순 상세 왕복 때문에 재생성하지 않는다. 한 번에 보이는 main은 하나다. 경로별 스크롤 위치도 저장한다.

도전 결과나 정답에서 굵은 텍스트 링크로 모델 정보에 접근한다. 사용된 모델 정보 보러가기는 상자/버튼 배경 없이 표시한다.

앱을 실제로 떠났을 때 AI 초기화하던 기존 visibility/pagehide 정책은 유지한다. 외부 사이트·공유 UI·키보드·closeView의 세부 기기 동작은 실제 토스 기기에서 별도 확인해야 한다.

## 쓰기 요청·늦은 응답

공통 API client는 GET 외 요청의 시작/종료를 탐색 계층에 알린다. 요청 중 `<`·탭·링크 이동은 차단한다. 정원 저장/버리기, 구매, 친구 추가·삭제, 계정 삭제 팝업은 처리 중 닫기 동작도 제한한다.

챌린지 제출·정원 저장·구매·게임 완료는 응답을 기다린 사이 다른 화면으로 이동했다면 이전 화면의 완료 callback이 새 화면으로 강제 이동시키지 않도록 origin을 확인한다. 서버 처리가 취소됐다는 의미는 아니며, 확정 상태는 서버 조회로 확인한다.
