# 시도별 게임 배치 보강 (2026-11-11)

기존 API는 새 플레이마다 crypto.randomInt로 seed를 발급한다. 같은 activePlay를 이어하면 같은 seed/버전을 유지하는 것이 정상이다. 길건너기는 차선/차량 속도/방향/위치가 seed 기반이며 점프 달리기도 장애물 크기/간격이 seed 기반이다. 숲길 달리기는 초반 안전 경로가 중앙 고정이고 이후3패턴의 단순 순환/반전만 사용해 시각적으로 반복될 수 있었다.

v12 변경:

- 점프 달리기/숲길 달리기 첫 장애물 거리도 seed에 따라 변동한다.
- 숲길 달리기 초반 안전 경로를 seed와 진행 순서로 선택한다.
- 이후3종 안전 경로는3묶음 주기마다 순서를 섞고, 각 묶음의 좌우 반전과 시작 위치를 seed로 바꾼다. 단순한 무작위 차단 대신 통과 가능한 경로와 두 칸 전환의 최소 시간은 유지한다.
- 길건너기는 기존 시도별 seed 기반 차량/차선 생성을 유지한다.
- 같은 seed/버전/입력이면 같은 결과가 나와 서버 replay 검증을 유지한다. Math.random을 시뮬레이션에 넣지 않는다. 시도마다 달라지되 일부 구간이 우연히 같은 것은 가능하다.
- 기존 index 소스를 legacy-v11.ts로 보존하고 초기화/step/replay/점프/차량/코인 버전 분기를 추가했다. 기존 activePlay는 v11로 끝내고 새 플레이가 v12를 사용한다.

검증: 게임 테스트21개 통과. 24개 seed에서 세 게임의 배치 다양성과 replay 정합성/이전v11 동작 확인. 30개 seed의 경로 반복/양쪽 레인 분포/회피 시간 테스트 통과. 회피만 하는 테스트 드라이버는 초반 선택적 코인을 모두 먹는다고 가정하지 않도록 수정했으며 물리적 획득과 보상 상한 검증은 유지한다.

공유 패키지 빌드 후 API가 이전 모듈을 메모리에 읽어둔 경우 재시작해야 새 플레이에 적용된다. 재시작 시 기본 로컬 메모리 데이터가 초기화되므로 사용자가 실행한다. UI 새로고침만으로 기존 게임 seed를 바꾸지 않는다. 원격 DB/Render 배포와 브라우저 플레이 검증은 이번에 하지 않았다.
