# AIMI 운영 업데이트 점검

갱신: 2026-11-13. **앱인토스 배포는 완료됐다.** 아래 항목은 다음 버전의 회귀 점검 목록이며, 최초 출시가 아직 대기 중이라는 뜻이 아니다. 당시 Gate 1~3 준비 기록은 [운영 이력](../archive/RELEASE_HISTORY.md)과 과거 감사 보고서로 구분한다.

## 변경 때 확인할 항목

- **앱 연결:** 시작·익명 인증·세션 복원·닉네임 저장·재접속 기록 유지.
- **거래:** 출석/팁/챌린지/구매 중복 방지, 예산·횟수·일일 경계, 실패 시 복구.
- **미션:** 게임 시작/중단/재진입, 첫 챌린지 제출 후 게임 차단, 결과·정답 해설·홈 복귀.
- **AI:** 기능별 독립 한도·잔여 횟수, 개선문 인계 후 실제 추천 요청 차감, 실패/타임아웃 처리, 필요한 고지·결과 표시.
- **소셜:** 코드 요청·상대 수락·상호 삭제·친구 정원 접근 권한·기록 표시. 실제 두 사용자 검증 여부를 별도로 기록.
- **UI:** 공식 내비게이션·닫기·시스템 뒤로가기, 안전 영역·키보드·320~480px·글꼴·스크롤·확대 방지.
- **운영:** HTTPS·서버 권한·비밀값 비포함, API live/ready, 콘텐츠 승인/버전/일정, 호출 중복·재시도 제어.
- **산출물:** AIT deploymentId·해시·소스 버전, 필요 시 API/DB 버전, 테스트 결과·콘솔 공개 버전.
