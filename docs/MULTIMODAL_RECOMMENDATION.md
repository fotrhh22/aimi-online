## 출력 분야 직접 선택·분야별 분석 (2026-11-11)

- 추천 UI에서 AI 자동 선택을 제거했다. 사용자가 텍스트/이미지/영상을 선택하고 해당 분야의 입력 안내에 업무를 입력한다. 분야 변경은 기존 분석/추천/미디어 조건을 비우며 새 분석이 필요하다. 같은 분야의 등급 변경은 재호출하지 않는다.
- task-profile-v7: 공통 계약/호출을 유지하며 선택 분야별 시스템 지시를 붙인다. 출력은 선택값으로 고정하고 명시 제작 조건/최소 적정 모델군만 분석한다. 명백히 다른 산출물 요청은 outputMismatch 또는 반환 출력 불일치로 AI_OUTPUT_MISMATCH(422), 한국어 안내 후 추천 중단. 모호한 업무는 선택 분야로 해석한다.
- 분석 캐시에 출력 분야를 포함해 같은 문장을 다른 분야에서 분석할 때 재사용하지 않는다. 출력 미지정 구형 API 호출만 기존 자동 판정/개선기 분석 재사용 호환을 유지한다. 실제 UI는 항상 출력값을 전송한다.
- 검증: 타입 검사/자동 테스트74개 통과. 합성 API 테스트로 image/video별 프롬프트/분야별 추가 호출/동일 분야 등급 재사용/충돌422를 확인했다. 실제 Gemini 호출·브라우저 검증·원격 배포·DB 변경 없음. 실행 중 API가 watch 모드가 아니면 재시작 후 새 프롬프트 적용.

## 이미지·영상 추천 설정 UI 간소화 (2026-11-11)

- 추천 화면의 작업·해상도·비율·참조 수·영상 길이·오디오 입력 폼을 제거했다. 추천 결과가 있을 때만 동일 비용 비교 기준을 한 줄로 표시한다. 조건 변경은 자연어 요청으로 받는다.
- 명시 조건 추출·지원 기능 검사·동일 설정 비용 계산은 유지한다. 누락 조건은 내부 비교 기본값이며 화면에 안내한다. 편집의 참조 수 미지정은 비교용 1장 가정, 명시된 0장은 덮어쓰지 않고 기존 비교 불가 검사를 따른다. 실제 이미지 업로드/제작을 수행한 것으로 간주하지 않는다.
- 새 분석 요청에 직전 결과의 media 설정을 재전송하지 않아 이전 해상도·길이가 새 요청을 덮어쓰지 않게 했다. 출력 종류·등급을 바꿀 때는 기존 분석을 재사용한다.
- 검증: 타입 검사 통과, 자동 테스트74개 통과. 브라우저 검증은 사용자 요청에 따라 생략했다. 원격 배포·DB 변경 없음.

## 처리 순서

사용자 업무 → 최종 outputKind → 필요한 입력 requiredInputModalities/도구 → 해당 분야의 최소 적정 Small/Medium/High → 지원 설정 필터 → 계산 가능한 동일 조건 비용순 최대3개.

- 생성할 결과물은 입력이 아니다. text→image, text→video, text→speech는 텍스트 입력이다. 사진 설명은 image 입력+text 출력이다. 영상 대본·로고용 프롬프트 작성도 text 출력이다.
- 새로운 런타임 분석에 outputKind/requiredInputModalities가 없으면 AI_INVALID_OUTPUT. 과거 저장 타입의 선택 필드는 이전 결과 읽기 호환용이다. 새 버전 해시로 과거 분류 캐시와 분리한다.
- LLM은 모델명·가격·벤치마크를 선택/생성하지 않는다. 제품군·비용 계산은 코드/고정 자료가 담당한다.
- outputKind: text/image/video/audio/speech/transcription/embeddings/rerank/decisions. 복수 결과 요청은 핵심 최종 출력 하나와 나머지 미확정 정보를 표시한다. 멀티스텝 복합 제작 파이프라인을 자동 견적하는 구현은 아니다.

## 모델군과 근거

텍스트는 기존 model-groups-v3를 유지한다. 생성 분야는 content/policies/media-model-groups-v1.json의 제품 설명/출처/명시적 등급 결정을 사용한다. 이미지 Small13/Medium25/High23, 영상 Small6/Medium19/High8이다. AIMI 제품 포지셔닝이며 크기/실측 생성 품질/AA 점수 인증이 아니다. 가격 분위수나 LLM 이름 추정으로 분류하지 않는다. 새 모델은 고정표 검수 전 탐색용 임시 Medium·추천 제외다. 음성·기타 전문 출력도 별도 정책 검수 전 자동 추천하지 않는다.

## 비용 비교

- 이미지 기본 가정: 1장/1K/1:1/참조0장, 입력문200토큰. 엔드포인트가 요청 해상도·비율을 명시적으로 지원할 때 장당 또는 MP 단가와 알려진 부가 입력비만 계산한다. 해상도 미확인은 기본1K라고 추정하지 않는다. MP는 정사각 1024²/10⁶으로 계산하고 다른 비율의 정확한 픽셀 수를 추측하지 않는다.
- 해상도·비율·참조 장수는 선택 엔드포인트의 지원 범위를 확인한다. 편집은 참조 이미지가 필요하며 참조 토큰 과금은 토큰 수를 모르면 견적 후보에서 제외한다.
- 이미지 출력 토큰 단가만 있는 모델은 목록에 남기고 장당 비용으로 임의 환산하지 않는다. 가격 variant는 요청 해상도 또는 일반 기본 요금만 사용한다. 품질별 비용이 미확정인 경우 임의 최저 조건을 선택하지 않는다.
- 영상 기본 가정: 6초/720p/16:9/오디오 미요구/참조0장. 명시된 USD초당 또는 US cent초당 SKU를 변환한다. 요청 길이를 지원하지 않으면 다른 길이로 몰래 비교하지 않는다. 4K/오디오 요구 시 해당 지원과 SKU를 확인한다.
- 영상 토큰만 있는 가격, 참조/편집/업스케일의 검증되지 않은 가격 조합은 자동 비용순 추천에서 제외한다. 목록/원본 단가/지원 조건은 상세에서 탐색 가능하다.
- 선택 설정은 UI에 표시·수정 가능하며, 입력·조건 미변경 시 등급·출력 형태 비교는 로컬 코드로 재계산하므로 추가 Gemini 호출/사용자 한도 소모가 없다.
- 매체 추천은 지원 조건+계산 가능 공개 가격 후보이며 실제 생성 품질·성공률 순위가 아니다. 텍스트 AA Intelligence/Coding/토큰 속도를 생성 품질 필터로 강제하지 않는다. 후보가 부족하면 타 분야로 채우지 않는다. 가격은 미래 시점 불가/30일 이내 조건을 유지한다.
