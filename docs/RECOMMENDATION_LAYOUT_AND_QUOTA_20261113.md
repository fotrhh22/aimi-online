# 추천 화면·개인 한도·AI 안내 수정 · 2026-11-13

- `/v1/state`에 사용자별 날짜/개선기·추천 used/limit/remaining을 추가했다. 기존 상태 조회에 합쳐 별도 폴링이나 입력마다 호출을 추가하지 않는다. 실패한 요청의 반환분을 반영하고 두 기능/다른 사용자/다음날을 분리한다. 추천 화면에 오늘 남은 추천 횟수를 표시한다.
- AI_NOT_A_PROMPT는 개선/확장 결과가 요청문이 아니라고 검사가 판단한 오류다. 연결 실패를 뜻하지 않는다. 고정된 어미 검사에서 작성하라/정리하세요/분석하시오/제시해라 같은 정상 명령형이 누락돼 보완했다. 실제 답변형 거부와 수량/의도 보존 검사는 유지한다. 사용자가 본 실패 출력은 저장되지 않아 정확히 어느 문장이 문제였는지는 확정하지 않았다. 오류 문구는 요청문 형식 실패·횟수 미차감으로 바꿨다. 무제한 재호출은 추가하지 않았다.
- iOS 키보드가 visualViewport를 위로 이동시키는 경우를 추적해 shell 위치를 offsetTop과 맞췄다. 스크롤은 안전 영역 아래 본문만 담당한다. 화면/입력/flex/grid의 min-content 확장 방지,3개 출력 탭 동일 너비,등급별 고정 컬럼을 적용했다. 모델 목록 내부 세로 스크롤은 유지한다.
- AI 안내는 기능별로 구분한다. 추천: ‘업무를 분석하고 모델군을 판단하는 AI는 Google Gemini예요. 분석을 위해 입력 내용이 Google에 전달돼요.’ 개선기: ‘질문을 다듬는 AI는 Google Gemini예요. 개선을 위해 입력 내용이 Google에 전달돼요.’ 이미지 챌린지의 규칙 채점과 세부 모델을 고르는 비용 계산에는 Gemini를 쓰지 않는다.
- 고객 문의/개인정보 URL은 PRIVACY_AND_SUPPORT_PLAN.md, legal/PRIVACY_DRAFT.md에 준비안으로 정리했다. 실제 이메일·운영자·보유기간·외부 처리 계약 확인 후 정적 HTTPS 페이지로 게시한다. 미확정 URL이나 연락처를 앱에 넣지 않았다.

## 최소 검증

타입 검사·API/AIT 빌드, 관련 회귀2개(명령형 요청문/답변 구분,사용자·기능·날짜별 read-only 잔여횟수)만 로컬 실행했다. 실제 Gemini 유료 호출 없음. 추천 화면은320/393px에서 긴 입력·이미지 결과·등급 너비 유지·가로 넘침과 모의 키보드 visualViewport 이동만 확인했다. 실제 iPhone 키보드는 새 번들 QR에서 재확인해야 한다. 전체 화면 재조사는 실행하지 않았다.

새 일반 토스 번들: `output/releases/toss-recommendation/AIMI_RECOMMENDATION_LAYOUT.ait`. 기존 닉네임/소셜 변경도 포함한다. SQL/인증서/환경변수 변경 없음.
